# EHQ Phone Reviews

Public GitHub Pages site for Blake to watch Elite Human HQ Reel review cuts on iPhone.

- Site: https://hoops85.github.io/ehq-phone-reviews/
- Publish from the studio box with `build/publish_phone_review.py` (see production-os/13-PHONE-REVIEW-LINKS.md in the main workspace).

Each `reviews/<slug>/` has `index.html` + `video.mp4` (720p silent H.264).
